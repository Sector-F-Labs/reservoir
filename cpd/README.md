# Change Proposal Documents (CPD)

This directory contains Change Proposal Documents (CPDs) for the Reservoir project. A CPD is a document that outlines a proposed change, new feature, or architectural modification.

The purpose of a CPD is to:

- **Formalize proposals:** Provide a clear and detailed description of the proposed change.
- **Facilitate discussion:** Serve as a basis for technical discussions and reviews.
- **Document decisions:** Record the rationale and decisions behind significant changes.

Each CPD should be placed in its own subdirectory, named after the proposal (e.g., `0001-file-based-storage`).
